# End a large session's diagnosis with a written handoff, not a longer turn

The costliest sessions came from long turns that kept every tool result in context, and implementation was approved inside a chat still carrying failed dry runs and probe dumps. Once a session is past the context-size nudge, a finished diagnosis is written down before implementing: the conclusion, the files and line ranges to open, and the hypotheses ruled out, on the issue when there is one. A fresh session starts from it, and a small diagnosis in a lean session skips it.
