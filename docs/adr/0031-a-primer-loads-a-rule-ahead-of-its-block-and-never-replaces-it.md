# A Primer loads a rule ahead of its block, and never replaces it

Agents met a rule only when a block or nudge refused them, so each refusal cost a retry. A [Primer](../../runner/GLOSSARY.md) is a skill the agent invokes itself to load the rule an action needs before taking it. It is a rung ahead of its block or nudge, never in place of one: invoking it is the model's choice, so a Primer reduces refusals rather than ending them, and the block stays. Its description is one line of about 25 words or fewer, because every description is loaded on every task. Its body injects rule sections from the rule's home, not their reasoning. No rule lives only in a Primer, as none lives only in a hook. On the enforcement ladder a Primer sits below path triggers and above router pointers: a path trigger fires on the folder touched whatever the agent chooses, while a Primer and a router pointer both wait on the agent's choice, and a Primer's description names the action and its body brings the rule itself, where a router row only points at a file to open. Every user-invoked skill stays user-invoked, and Primers are the only model-invoked skills added. This extends [ADR 0011](./0011-hard-block-only-narrow-patterns-and-nudge-the-rest.md)'s narrow blocks and [ADR 0019](./0019-place-each-rule-on-the-highest-enforcement-rung-with-agents-md-the-only-router.md)'s ladder. So don't remove a block or nudge because a Primer now precedes it.
