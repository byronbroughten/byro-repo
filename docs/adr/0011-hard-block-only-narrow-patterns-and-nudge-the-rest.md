# Hard-block only narrow patterns, and nudge the rest

A guardrail that starves the agent of information or cuts off legitimate work costs more tokens than it saves. So only two patterns are hard-blocked: a Bash read of `columnConfigs.ts`, closing the gap in the `Read` deny that already named grepping the sheet key as the route, and a whole-file dump of a large file; each block names the alternative. A read-count reminder and context-size warnings only nudge, and never stop a turn. Every hook fails open, so a bug in one never blocks unrelated work.
