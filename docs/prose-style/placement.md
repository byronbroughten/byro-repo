# Placement

Why a rule sits as high on the enforcement ladder as it can, and why the root AGENTS.md admits so little.

## The highest rung

Each rung reaches fewer agents than the one above it, so a rule moves up whenever it can. The argument and its instances are in [`agent-behavior-design.md`](../agent-behavior-design.md#put-each-rule-where-it-gets-followed-and-its-reasoning-one-pointer-away).

## The root AGENTS.md

Its cost, and why no byte cap stands in for the judgment, is [`prose-files.md`'s cost section](../agents/prose-files.md#what-an-addition-to-agentsmd-costs). Stating the net bytes lets the developer judge the addition without diffing the file.
